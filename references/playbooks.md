## 模块 1：quote（查行情）

### 检查清单
1. **代码与市场对齐**：
   - A 股：区分沪市（`.SS` / `SH`）、深市（`.SZ` / `SZ`）、北交所（`.BJ`），注意涨跌停限制（10% / 20% / 30%）。
   - 港股：标准 4~5 位代码（如 `0700.HK`），注意港币计价与人民币 / 美元财报的汇率折算。
   - 美股：注意 ADR 与本土股的换算比例（如台积电 `TSM` 1 ADR = 5 普通股，阿里 `BABA` 1 ADR = 8 股 `9988.HK`）。换算比例以检索到的最新公告为准。
2. **复权口径**：历史区间涨跌幅与均线用**前复权**；市值用**最新未复权价 × 最新稀释总股本**。
3. **异动归因**：只写有公开事件支撑的归因，并附事件日期与来源。找不到对应事件时写"未找到对应公开事件"。原因：K 线形态本身不构成解释，编造催化剂会误导决策。

### 输出结构
- `最新价（时间戳）/ 市值 / 52 周高低点及所处分位`
- `近 5 日 / 20 日 / 年初至今涨跌幅 vs 基准指数超额收益`
- `关键放量异动日 + 对应事件（财报日、指引更新、监管 / 行业政策）`

### 完成标准
每个价格都有时间戳和来源；每条异动归因都有事件日期，或明确写"未找到"。

## 模块 2：fundamentals（翻财报）

定位：管筛选，不管判断。圈出异常点，指明回查原表的位置。

### 检查清单
1. **增长与盈利质量**：
   - 营收同比 / 环比增速 vs 核心主营分部增速（剔除并表或低毛利杂项业务拉动）。
   - 毛利率、经营利润率（OPM）、ROE 趋势：区分规模效应改善与削减研发 / 营销费用硬挤出的利润。
2. **现金流 vs 利润**：
   - `经营活动现金流净额 (OCF) / 净利润`：长期低于 `0.8` 标黄排查。
   - `FCF = OCF - CapEx`；再扣除 SBC（股权激励费用），得到**股东真实自由现金流**，并给出 SBC 占营收比例。
3. **资产负债表排雷**（每项给出回查的附注名称）：
   - **应收与存货背离**：应收或存货增速显著高于营收增速 → 回看附注《应收账款账龄分析》《存货跌价准备》。
   - **非经常性损益**：Non-GAAP 利润长期大幅高于 GAAP 利润 → 回看重组费用、公允价值变动、一次性补贴明细。
   - **净负债与短债压力**：`现金及短期投资` vs `一年内到期有息负债`，以及利息覆盖倍数。

### 完成标准
每个异常点都对应一个具体附注或报表章节；无法取得的指标标 `N/A（原因）`。

## 模块 3：earnings（拆业绩会）

### 第 0 步：原文摘录
先从纪要中逐字摘录与指引、利润率、订单、风险相关的原句，编号并标注发言人，放在"原文摘录"区块。后续分析只引用摘录编号。原因：纪要很长，先锚定原文能防止把转述当原话，也便于用户核对。拿不到纪要原文时，说明缺失，不凭记忆复述管理层发言。

### 三把手术刀
1. **官话 → 财务核查项**：
   - "阶段性加大战略投入" → 核对销售费用率 / CapEx 增速是否伴随 ROI 或指引同步上调；若无，则是利润率承压。
   - "外部环境压力 / 客户决策周期拉长" → 核对下季订单（Bookings / RPO）、合同负债、应收周转天数或同店增长是否放缓。
   - "符合内部预期" → 对比三个月前的定量 Guidance 中枢，判断是贴上限还是擦下限。
2. **跨期 Redline Diff**：
   - 本季核心业务定调 vs 上季业绩会：哪些曾重点宣传的增长引擎本次不再提及，或从定量改为定性。
   - 风险提示段落的新增与删除。
   - 没有上季纪要时，Diff 标 `N/A（缺上季纪要）`。
3. **Q&A 回避矩阵（Evasion Matrix）**：

   | 分析师追问的具体指标 | 高管回答摘要（摘录编号） | 回答类型：直接给数 / 模糊转移 / 拒绝披露 |
   | :--- | :--- | :--- |

### 完成标准
每个结论都引用至少一条摘录编号；回避矩阵覆盖所有追问具体数字的问题。

## 模块 4：dcf（算估值）

定位：当尺子用，不当目标价用。

### 检查清单
1. **先跑逆向 DCF**：用当前股价反推未来 5 年隐含 FCF 复合增速，再与公司近 3 年 FCF 增速、行业天花板对比，判断价格计价的是悲观、合理还是极度乐观。
2. **参数透明**：列出 `基准年 FCF`、`净债务（有息负债 - 现金）`、`稀释总股本`、`WACC`、`永续增长率 g`，每项附来源。g 通常不超过长期名义 GDP 增速（`2%~3%`）。
3. **币种与单位统一**：港股、中概股常见"港币股价 + 人民币 / 美元财报"。先把 FCF 与净债务换算成股价币种（注明汇率和日期），再统一数量级。
4. **FCF ≤ 0 或处于周期低点**：不直接代入当期 FCF。构造归一化稳态 FCF = `稳态收入 × 目标 FCF 利润率`，写明稳态年份、收入假设、利润率参照（如成熟同行中位数），并把输出标为"归一化 DCF"。同时用每股净现金、最近融资价格等作为辅助锚点。
5. **运行脚本并做输出检查**：见 SKILL.md "脚本输出检查"。终值占 EV 比例 >75% 时，提示估值对远期假设高度敏感。

### 完成标准
所有参数有来源；币种统一；输出检查三项全部通过或已在正文说明。

## 模块 5：diversification（看持仓结构）

### 检查清单
1. **表层行业集中度**：按 GICS / 申万一级行业汇总权重。
2. **底层因子穿透**：
   - 为每只持仓标注一个**最核心的宏观 / 产业驱动因子**（如 `AI算力资本开支`、`长端利率下行`、`国内地产链修复`、`出海关税敞口`、`大宗商品通胀`）。
   - 因子标注是你的判断，不是数据。在输出中列出标注依据；归属有争议的持仓请用户确认。
   - 多只不同行业持仓共享同一因子且合计权重 `> 30%` 时，脚本发出"伪分散（Disguised Concentration）"预警。

### 完成标准
脚本输出完整；每个因子标注有一句依据；所有预警都在正文解释了共同的风险传导路径。

## 模块 6：stress-test（证伪）

### 输出结构
1. **承重墙假设**（Load-Bearing Assumptions）：2~3 条支撑看多逻辑的核心前提。
2. **事前验尸**（Pre-mortem：假设 12 个月后亏损 30%）：
   - 路径 A（报表证伪）：哪个核心指标恶化？
   - 路径 B（竞争 / 产业证伪）：同行或上下游出现什么反证？
   - 路径 C（估值与资金面双杀）：叙事退潮时，估值倍数退守到历史什么分位？
3. **3 条 Kill Criteria**：每条写成 `指标 + 阈值 + 观测时点 + 数据来源`。

   - 合格：`2026Q4 财报数据中心毛利率 < 70%（来源：10-Q 分部披露）`
   - 不合格：`基本面恶化就卖`（无阈值、无时点，无法执行）

### 完成标准
3 条 Kill Criteria 都能在未来 1~2 个季度内，由公开数据判定"触发 / 未触发"。

## 模块 7：arti（串流程与留档复盘）

### 建档流
按 SKILL.md "ARTi 全流程"清单执行。顺序：行情位置 (1) → 财报疑点 (2) → 业绩会言行比对 (3) → 逆向 DCF 标尺 (4) → 组合因子冲突 (5，可选) → 反方挑刺与 Kill Criteria (6) → **人工确认** → 写入 Decision Journal (7)。

### 复盘流（用户要求复盘或提供历史留档时）
1. 读取 `~/decision-journal/`（`journal --dir` 的默认目录）下该标的的历史留档。
2. 用最新数据逐条核对：每条承重墙假设是否成立？每条 Kill Criteria 是否触发？每个判定附数据与来源。
3. 识别"逻辑漂移"（Thesis Creep）：
   - 短线交易失败后被改称"长线价值投资"。
   - 股价上涨掩盖了已经恶化的原始假设。
4. 在留档文件的"事后复盘记录"表格末尾追加一行（直接编辑该 Markdown 文件，不重新运行 `journal`，否则会覆盖原记录）。用户确认离场后，把 front matter 中的 `status` 改为 `closed`。

### 完成标准
每条原始假设和 Kill Criteria 都有"维持 / 证伪 / 触发 / 未触发"判定；复盘行已写入文件。
